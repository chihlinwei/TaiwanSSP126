# Installation

### To install the package, open R and type:


``` r
install.packages("devtools")
```

### Then, you can install TaiwanSSP126:


``` r
devtools::install_github("chihlinwei/TaiwanSSP126", dependencies = TRUE)
library(TaiwanSSP126)
```
